canonical source proposals, an opt-in CC0 texture cache and a source-bound IFC4

evidence owner-approval receipt are required before stable publication. This
scope document and the build manifest alone do not authorize publication.

## Exact limits

This is a local-source, fixed IFC4 exchange with known classes and explicit
requirements; it is not a certified MVD, actual client IDS/exchange approval or
regulatory/structural/manufacturing certification. Native PBR is preserved in
Blender/GLB; IFC carries source/material identities and explicit custom quantities.
Room prism volume uses the supplied level height; it is not surveyed clear ceiling
volume. Unknown source materials stay UNKNOWN. Stable GUIDs require a persistent,
globally unique project identity; synthetic example IDs are not real federation IDs.

Native outputs are frozen editable meshes, not working upstream parametric panels.
Windows currently share an opaque component material; columns are open-ended
faceted display surfaces. Decorative tile patches are not complete roofs. Cloth,
slat/rail/hardware dimensions are nominal upstream controls; only declared anchors
and all exported/evaluated surface fidelity are independently checked. The accepted
fixtures do not prove every parameter combination. No source dimensions are invented
for a real project, and no user original or live-host document is edited.

Indexed impact is partial: unindexed drawings, external families/type catalogs and
professional constraints remain UNKNOWN. OS/database/executable storage and selected
owner key/receipt pins remain trusted; signatures are not human-presence credentials,
external anti-rollback storage or an OS sandbox. Revit/AutoCAD live transactions and
rollback are not implemented by this source ledger. Full #13/#15/#45 general-client,
professional and live-host criteria remain open rather than being falsely closed.
